# 退货与退款处理规范（演示样例）

政策类别：AFTERSALES_REFUND  
版本：1  
生效日期：2025-01-01  
适用范围：演示商家售后客服流程。

## 申请前核对

客服应先核对当前商家、订单号、订单状态、实付金额与已退款金额。未查询到订单或关键信息不一致时，不得承诺退款金额，应补充核验或转人工。

## 申请与审核

退款诉求由客服整理为待确认申请。提交后由具备审批权限且不是申请人的人员审核。审批依据应记录订单事实、用户诉求和适用政策；未经审批不得执行退款。

## 演示环境执行边界

演示系统仅在具备权限的人员审批通过后，才会在虚构订单上写入本地退款记录并累计已退款金额。该过程不连接支付渠道、不转移资金。客服不得向用户承诺支付渠道已实际退款。

## 信息不足

本样例不规定具体退款时限、费用承担或法定退货条件。政策没有明确覆盖的问题应由人工确认，不得由助手自行补充期限或保证审批结果。
