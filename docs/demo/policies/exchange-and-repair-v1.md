# 换货与维修受理规范（演示样例）

政策类别：EXCHANGE_REPAIR  
版本：1  
生效日期：2025-01-01  
适用范围：演示商家售后客服流程。

## 受理信息

客服应关联原订单，并记录商品 SKU、问题描述、发现时间及用户提供的照片或其他材料。信息不足时先向用户询问，不应推断商品质量责任。

## 工单与审批

助手可以整理换货或维修工单草稿，由客服核对后确认创建。需要主管判断、仓库验货或线下维修的事项应分配给相应人员；助手不能代替人工检验或直接承诺换货结果。

## 库存与履约

库存建议只用于客服和仓库参考。演示系统中的调拨申请需经仓库角色审批，审批后的系统效果仅为创建本地调拨单并预留库存，不代表实物已经出库或送达。

## 信息不足

本样例不规定产品质保期限、维修费用、退换货法定条件或缺货补偿。没有明确政策依据时应转人工确认。
