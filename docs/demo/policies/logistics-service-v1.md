# 物流异常处理规范（演示样例）

政策类别：LOGISTICS  
版本：1  
生效日期：2025-01-01  
适用范围：演示商家售后客服流程。

## 事实核查

客服应先查询订单状态、承诺送达时间和承运商已记录的物流事件。物流事件缺失或长时间没有更新时，只能描述系统中最后一条记录，不得仅凭沉默判断包裹丢失。

## 异常升级

显示承运异常、超过订单承诺送达时间，或用户称已签收但未收到时，应保留订单号、运单事件和用户描述，创建待跟进工单并转人工核查。需要联系承运商的事项由人工执行。

## 对客答复

答复应区分系统记录与用户描述，并说明尚未核实的事实。不得承诺赔付、退款或新的送达时间，除非适用的已发布政策和人工审批明确支持。

## 信息不足

本样例不规定物流赔付金额、统一异常时限或承运商服务等级。需要这些信息时转人工处理。
