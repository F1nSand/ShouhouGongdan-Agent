## 统一约定

- 主场景：中小型电商商家的内部客服工作台。
- 主角色：客服、客服主管、仓库运营、管理员；消费者入口放在后续阶段。
- 首期商家：一个演示商家；业务记录保留 tenant_id，并验证商家隔离。
- 数据源：固定演示数据 + 可替换的订单、物流适配器。
- 退款：local-demo 模式在合成数据中真实更新订单退款累计额并写幂等本地账本；不调用支付网关。
- 调拨：审批通过后创建本地调拨单并预留库存，实物出入库放在后续阶段。
- 状态与接口以数据模型、接口文档为准，变更同步需求、实施计划和测试。
- 指标数值为验收目标；实际结果另外保存实测报告。
